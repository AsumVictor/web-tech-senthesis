How do I get a token?
  1. Open Canvas and go to Account → Settings.
  2. Scroll to Approved Integrations and choose + New Access Token.
  3. Give it a name (like "Web Tech Report"), then generate it and copy it here.

Your token is kept in a secure cookie on this device that page scripts can't read. The server passes it to Canvas for each request and never saves it. You can delete it in Canvas at any time.
